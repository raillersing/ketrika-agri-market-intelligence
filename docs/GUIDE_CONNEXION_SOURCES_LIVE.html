1. OCHA HDX HAPI — L'API Moderne des Prix Alimentaires Testé 100% Fonctionnel

Comment utiliser la nouvelle Humanitarian API (HAPI) d'OCHA sans se perdre dans la complexité de l'ancien portail CKAN.

Critère ❌ L'Ancien HDX (CKAN / Téléchargement CSV direct) ✅ Le Nouveau HDX HAPI (hapi.humdata.org)
Accès Téléchargement brut de fichiers CSV de 50 Mo, bloqué par Cloudflare (Erreur 403). API REST moderne en JSON propre, documentée sur Swagger OpenAPI.
Authentification Complexe, nécessite des jetons secrets CKAN et des headers spécifiques. Simple `app_identifier` : chaîne Base64 publique NomApp:email.
Filtres Aucun : il faut télécharger tout le fichier mondial et le découper. Filtre direct par pays : location_code=MDG, par produit ou date.
Données Madagascar Colonnes HXL désordonnées, noms de marchés non uniformisés. GPS exacts, P-Codes (MG11, MG11107), devises MGA, catégories PPN normalisées.

  • Explorer l'API interactivement (Swagger OpenAPI)
    OCHA met à disposition une documentation interactive complète où vous pouvez tester les endpoints directement sans écrire de code :

    • Documentation générale : https://docs.humdata.org/build/hdx-apis/hapi/available-data
    • Console Swagger interactive : https://hapi.humdata.org/docs
    • Section dédiée : Food Prices & Market Monitor sous /api/v2/food-security-nutrition-poverty/food-prices-market-monitor.
  • Les données PPN disponibles pour Madagascar
    En filtrant sur location_code=MDG, HAPI retourne exactement les produits suivis par Ketrika :
    Riz & Céréales
    Rice (local), Rice (imported), Maize (crushed)
    Tubercules & Huiles
    Cassava (fresh), Cassava (dry), Oil (vegetable, packaged)
    Légumineuses & Protéines
    Beans (haricot blanc), Beans (pois de cap), Beans (niébé), Groundnuts
    Marchés & Géographie
    Analamanga (Anjozorobe, Manjakandriana, Talata...), Vakinankaratra, Atsinanana...
  • Activer dans registry/sources.yaml
    Réglez le connecteur dans le registre de Ketrika pour interroger HAPI :
    registry/sources.yaml 
    - source_id: wfp_hdx_mdg
  name: "WFP Food Prices – Madagascar (HDX HAPI)"
  owner: "World Food Programme / OCHA HDX"
  source_family: un_wfp
  priority: P1
  status: active
  access_method: api
  connector: ketrika.connectors.wfp_hdx_mdg:WfpHdxMdgConnector
  entrypoints:
    - url: "https://hapi.humdata.org/api/v2/food-security-nutrition-poverty/food-prices-market-monitor?location_code=MDG&output_format=json"
      kind: api
      verified: true
      verified_at: "2026-11-06T00:00:00Z"
2. NASA POWER Agroclimatology (API Journalière) Testé HTTP 200 OK

Données agro-météorologiques par points géographiques (précipitations, températures min/max, humidité).

  • Statut d'accès : 100% Libre & Gratuit
    L'API NASA POWER est en Domaine Public. Elle ne nécessite **aucune clé API secrète ni paiement**. Elle a été testée et répond avec succès en HTTP 200 sur les coordonnées de Madagascar (ex: Antananarivo 47.5°E, -18.9°S).
  • Activer la source dans registry/sources.yaml
    registry/sources.yaml 
    - source_id: nasa_power
  name: "NASA POWER Agroclimatology Daily Point API"
  owner: "NASA Langley Research Center"
  source_family: nasa
  priority: P1
  status: active
  access_method: api
  connector: ketrika.connectors.nasa_power:NasaPowerConnector
  cadence: daily
  freshness_sla_days: 7
  entrypoints:
    - url: "https://power.larc.nasa.gov/api/temporal/daily/point"
      kind: api
      verified: true
      verified_at: "2026-11-06T00:00:00Z"
  • Lancer la collecte réelle sur les 23 régions
    PowerShell 
    .\scripts\dev.ps1 backfill nasa_power
3. Banque Mondiale Pink Sheet (Cours Mondiaux FOB) Testé HTTP 200 OK

Cotations FOB mondiales officielles du riz blanc 25% brisures, huile de palme brute, blé et sucre.

  • La Nouvelle URL Officielle Validée
    La Banque Mondiale a mis à jour ses points d'accès en 2026. L'ancienne URL DataBank bloquait en 403. La nouvelle URL de publication mensuelle validée avec succès est :
    URL Officielle Banque Mondiale (Novembre 2026) 
    https://thedocs.worldbank.org/en/doc/74e8be41ceb20fa0da750cda2f6b9e4e-0050012026/related/CMO-Historical-Data-Monthly.xlsx

4. Fret Maritime International & Corridors RN2 / RN4 Testé HTTP 200 OK

Acheminement Asie → Port de Toamasina et acheminement terrestre vers les grands bassins de consommation.

  • Flux Hebdomadaire Public Drewry World Container Index
    Drewry publie le résumé mondial officiel chaque jeudi sans abonnement payant :
    URL Drewry WCI 
    https://www.drewry.co.uk/supply-chain-advisors/supply-chain-expertise/world-container-index-assessed-by-drewry
  • Barèmes de Corridors Terrestres Intégrés
    Ketrika intègre les corridors de fret routier essentiels :
    • RN2 (Toamasina → Antananarivo) : corridor d'importation principal du riz et de l'huile.
    • RN4 (Mahajanga → Antananarivo) : corridor céréalier et bétail.
    • RN34 (Bongolava → Antananarivo) : corridor du maïs et manioc.
