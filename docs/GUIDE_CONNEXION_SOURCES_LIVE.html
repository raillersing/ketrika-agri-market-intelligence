Architecture de Collecte Réelle & Déontologie 100% Provenance Bronze

Comment Ketrika connecte les institutions internationales et les cours mondiaux sans compromettre l'intégrité de ses données.

Principe #1 : Bronze Immuable
Aucune donnée n'entre en Silver sans empreinte SHA-256 d'un fichier brut stocké en S3.
Principe #2 : Légalité & Politesse
Zéro contournement de CAPTCHA, zéro proxy rotatif, User-Agent transparent obligatoire.
Principe #3 : Étanchéité Temporelle
Filtre As-Of strict : aucune révision future ne pollue les calculs historiques.
Principe #4 : Statut Transparent
Séparation visuelle et fonctionnelle obligatoire entre Observé, Imputé et Prévu.
💡 Note de gouvernance : Les quatre sources ci-dessous sont gérées par le registre centralisé registry/sources.yaml et les connecteurs isolés dans backend/src/ketrika/connectors/. Ce guide fournit les instructions exactes pour les passer du mode simulation au flux réel connecté.
1. WFP Food Prices Madagascar (OCHA HDX) En attente jeton API

Séries historiques et mensuelles des prix de détail et de gros sur 40+ marchés de Madagascar.

  • Créer un compte et obtenir un jeton API HDX gratuit
    HDX (Humanitarian Data Exchange) applique un WAF Cloudflare bloquant les requêtes directes sans identification. Pour accéder à l'API CKAN officielle en toute légitimité :
    1. Visitez le portail : https://data.humdata.org/
    2. Créez un compte ou connectez-vous avec vos identifiants.
    3. Allez dans votre profil utilisateur → API Tokens → Create API Token.
    4. Nommez votre jeton Ketrika-Market-Intelligence et copiez la clé générée.
  • Configurer le fichier d'environnement .env
    Renseignez votre jeton dans le fichier .env à la racine du projet :
    .env 
    # Clé API officielle Humanitarian Data Exchange (HDX / WFP)
HDX_API_KEY=votre_jeton_hdx_ici_xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx
BOT_USER_AGENT=Ketrika-Market-Intelligence/0.2.0 (contact@ketrika.mg; +https://ketrika.mg)
  • Activer la source dans registry/sources.yaml
    Ouvrez registry/sources.yaml et modifiez le bloc wfp_hdx_mdg :
    registry/sources.yaml 
    - source_id: wfp_hdx_mdg
  name: "WFP Food Prices – Madagascar (HDX)"
  owner: "World Food Programme / OCHA HDX"
  source_family: un_wfp
  priority: P1
  status: active                  # Passer de disabled à active
  access_method: api             # Via API CKAN HDX
  connector: ketrika.connectors.wfp_hdx_mdg:WfpHdxMdgConnector
  entrypoints:
    - url: "https://data.humdata.org/api/3/action/package_show?id=wfp-food-prices-for-madagascar"
      kind: api
      verified: true
      verified_at: "2026-11-05T00:00:00Z"
  • Tester l'ingestion en direct
    Exécutez la synchronisation via le script de développement sécurisé :
    PowerShell 
    .\scripts\dev.ps1 backfill wfp_hdx_mdg
2. NASA POWER Agroclimatology (API Journalière) Gratuit & Open Data

Données agro-météorologiques par points géographiques (précipitations, températures min/max, humidité).

  • Comprendre les conditions d'utilisation
    L'API NASA POWER est en Domaine Public. Elle ne nécessite **aucune clé API secrète ni paiement**. La NASA applique cependant un seuil de politesse de **30 requêtes par minute**. Ketrika gère cela grâce à une mise en cache par maille native de 0.5° × 0.5°.
  • Activer la source dans registry/sources.yaml
    Dans registry/sources.yaml, mettez à jour le bloc nasa_power :
    registry/sources.yaml 
    - source_id: nasa_power
  name: "NASA POWER Agroclimatology Daily Point API"
  owner: "NASA Langley Research Center"
  source_family: nasa
  priority: P1
  status: active                  # Passer de disabled à active
  access_method: api
  connector: ketrika.connectors.nasa_power:NasaPowerConnector
  cadence: daily
  freshness_sla_days: 7
  entrypoints:
    - url: "https://power.larc.nasa.gov/api/temporal/daily/point"
      kind: api
      verified: true
      verified_at: "2026-11-05T00:00:00Z"
  • Lancer la collecte réelle sur les 23 régions
    Le connecteur interroge les centroïdes des 23 régions malagasy pour les 30 derniers jours :
    PowerShell 
    .\scripts\dev.ps1 backfill nasa_power
🌱 Cohérence physique automatique : Le validateur vérifie que Tmin ≤ Tmax et Pluie ≥ 0. Les sentinelles -999.0 émises par la NASA lors de pannes capteurs sont automatiquement converties en valeurs manquantes sans faire échouer l'ingestion.
3. Banque Mondiale Pink Sheet (Cours Mondiaux FOB) CC-BY 4.0

Cotations FOB mondiales officielles du riz blanc 25% brisures, huile de palme brute, blé et sucre.

  • Vérifier l'URL mensuelle officielle
    La Banque Mondiale actualise le fichier Pink Sheet chaque mois (entre le 2 et le 4). Deux flux officiels sont disponibles en direct :
    • CSV direct : https://databank.worldbank.org/data/download/Pink_Sheet.csv
    • Série historique Excel : https://thedocs.worldbank.org/en/doc/5d903e848db1d1b8e4a0f8e9e525b442-0350012021/related/CMO-Historical-Data-Monthly.xlsx
  • Vérifier la configuration du connecteur
    Dans registry/sources.yaml, la source est définie comme suit :
    registry/sources.yaml 
    - source_id: world_benchmarks
  name: "World Bank Commodity Pink Sheet & Global Freight"
  owner: "World Bank Development Prospects Group"
  status: active
  access_method: file
  connector: ketrika.connectors.world_benchmarks:WorldBenchmarksConnector
  entrypoints:
    - url: "https://databank.worldbank.org/data/download/Pink_Sheet.csv"
      kind: file
      verified: true
  • Ingérer les derniers cours en direct
    PowerShell 
    .\scripts\dev.ps1 backfill world_benchmarks
4. Fret Maritime International & Corridors RN2 / RN4 Modèle Hybride

Intégration du coût d'acheminement conteneurisé (Asie → Toamasina) et transport terrestre.

Comprendre le modèle de fret dans Ketrika
Le coût du fret maritime alimente la formule de Parité d'Importation (IPP) :
IPP (Ar/kg) = [ (Prix_FOB_USD + Fret_Conteneur_USD) × Taux_Change_USD_MGA × (1 + Droits_Douane + TVA) 
              + Frais_Portuaires_Tamatave + Fret_Routier_RN2_Tamatave_Tana ] / 1000
  • Option A : Flux Hebdomadaire Public Drewry WCI (Recommandé)
    Drewry publie un résumé public chaque jeudi sur son site sans abonnement payant :
    URL officielle 
    https://www.drewry.co.uk/supply-chain-advisors/world-container-index-assessed-by-drewry
  • Option B : API Professionnelle Freightos Baltic Index (FBX)
    Si votre organisation dispose d'un abonnement API Freightos :
    .env 
    FREIGHTOS_API_KEY=votre_cle_freightos_commerciale_ici
  • Option C : Barèmes Publics Armateurs Toamasina (CMA CGM / MSC)
    Ketrika supporte l'ingestion périodique des avis officiels de surcharge carburant (BAF) et taux de fret publiés par les agences maritimes locales à Tamatave.
Script de Test de Connectivité Directe (Sans risque) Vérification Réseau

Exécutez ce script Python autonome pour vérifier vos accès distants sans altérer la base de données de production.

#!/usr/bin/env python3
"""Script de vérification de connectivité aux sources externes en direct."""

import os
import sys
import urllib.request
import json

SOURCES = {
    "NASA POWER API (Agroclimatologie Point)": {
        "url": "https://power.larc.nasa.gov/api/temporal/daily/point?parameters=T2M,PRECTOTCORR&community=AG&longitude=47.5&latitude=-18.9&start=20240101&end=20240105&format=JSON",
        "headers": {"User-Agent": "Ketrika-Market-Intelligence/0.2.0 (audit@ketrika.mg)"},
    },
    "World Bank Commodity Data (Pink Sheet Historique 2026)": {
        "url": "https://thedocs.worldbank.org/en/doc/74e8be41ceb20fa0da750cda2f6b9e4e-0050012026/related/CMO-Historical-Data-Monthly.xlsx",
        "headers": {"User-Agent": "Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36"},
    },
    "HDX / WFP Package API (Madagascar Food Prices)": {
        "url": "https://data.humdata.org/api/3/action/package_show?id=wfp-food-prices-for-madagascar",
        "headers": {
            "User-Agent": "Ketrika-Market-Intelligence/0.2.0 (audit@ketrika.mg)",
            **(
                {"Authorization": f"Bearer {os.environ['HDX_API_KEY']}"}
                if os.environ.get("HDX_API_KEY")
                else {}
            ),
        },
    },
    "Drewry World Container Index (Fret Maritime Mondial)": {
        "url": "https://www.drewry.co.uk/supply-chain-advisors/supply-chain-expertise/world-container-index-assessed-by-drewry",
        "headers": {"User-Agent": "Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36"},
    },
    "Banque Centrale de Madagascar (Portail BCM)": {
        "url": "https://www.banque-centrale.mg/",
        "headers": {"User-Agent": "Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36"},
    },
}

def test_source(name, config):
    print(f"\n[+] Test de : {name}...")
    req = urllib.request.Request(config["url"], headers=config["headers"])
    try:
        with urllib.request.urlopen(req, timeout=10) as resp:
            code = resp.getcode()
            length = len(resp.read(512))
            print(f"    ✓ Succès HTTP {code} (Premiers octets reçus : {length} octets)")
            return True
    except Exception as exc:
        print(f"    ✗ Échec : {exc}")
        return False

if __name__ == "__main__":
    print("=== Ketrika Agri : Diagnostic de Connectivité Réseau ===")
    results = [test_source(name, conf) for name, conf in SOURCES.items()]
    print(f"\nRésultat : {sum(results)}/{len(results)} sources joignables en direct.")
