## Protections après réparation

La normalisation exclut la quarantaine de l'observation et de sa référence.
Une clé encore réservée par une ligne historique quarantainée est refusée avant
insertion ; aucun lien de révision artificiel n'est créé. Une référence source
quarantainée est refusée avant toute modification de l'observation précédente.
Le wipe refuse toute quarantaine active ; le CLI exige le laboratoire dédié et
l'isolation réseau effective. Sur le clone historique réel, le refus est vérifié
en transaction READ ONLY :1313 entrées avant/après et nouvelle comparaison SQL
identique. Cela ne constitue pas une reconstruction réussie AU-09.

concurrence SQL,7 anciens cas quarantaine,23 cas de comparaison,9 cas copie
